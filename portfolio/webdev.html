Art Around the World

Art Around the World was my final project submission for NMIX4020. I chose to utilize JavaScript as well as several APIs to create a website that could be used as a fun educational tool to learn more about art history. You can learn more about how I made the site Here!

APIs Used:

  • Met Museum of Art
  • MediaWiki Action API (Wikipedia) with TextExtracts Extension
  • REST countries
  • nominatim
  • CORS Anywhere
  • The Getty Research Institute's Art & Architecture Thesaurus® Online
  • Leaflet
  • Stadia Map's Stamen Toner
  • Country geoJSON Data
